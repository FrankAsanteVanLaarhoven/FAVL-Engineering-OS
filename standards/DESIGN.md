# Product and Interface Design Standard

Design must be task-led rather than decoration-led. Establish user roles, critical journeys, information architecture, system states, accessibility requirements, error recovery, and measurable usability outcomes before visual polish.

Requirements:
- WCAG-aligned semantics, keyboard operation, focus management, contrast, and reduced-motion support;
- responsive layouts and robust empty, loading, error, offline, permission, and degraded states;
- reusable design tokens and components;
- explicit confirmation for destructive or consequential actions;
- no dark patterns, deceptive urgency, inaccessible glass effects, or animation that impairs comprehension;
- performance budgets for critical journeys.
